ChatGPT Projects vs a folders extension: when to use each

Published November 25, 2026 · 5-minute read

Use ChatGPT Projects when a set of chats should share the same files, instructions and memory, and use a folders extension when you only want to file and find chats, especially across ChatGPT, Claude, Gemini and Grok; the two work together.

Disclosure: ConvoShelf is a folders extension and it is our product. The ChatGPT details come from OpenAI's Help Center article Projects in ChatGPT, read on November 25, 2026. We only compare what that page says that day; OpenAI changes Projects often. The ConvoShelf details come from its Chrome Web Store listing and the 1.2.0 code.

What ChatGPT Projects do

OpenAI says projects "keep related chats, files, and instructions together" so ChatGPT can use that context. From the help page:

  • Files. You can upload PDFs, spreadsheets, docs and images to a project. Free accounts get 5 files per project, Go and Plus 25, and Pro, Business, Enterprise and Edu 40.
  • Instructions. Project instructions apply only inside that project and override your global custom instructions.
  • Memory. A project can use default memory or project-only memory. With project-only memory, chats in the project don't use your saved memories from outside it.
  • Moving chats. Drag a chat onto a project, or open its menu and choose Move to project. After moving, the chat inherits the project's instructions and files. Chats created with a GPT can't be moved into a project.
  • How many. OpenAI says you can create an unlimited number of projects.
  • Sharing. Project sharing is available on Free, Go, Plus, Pro, Business, Enterprise and Edu. Shared projects always use project-only memory.
  • Deleting. Deleting a project permanently removes its chats and instructions, along with files stored only in the project.

What a folders extension does

A folders extension adds its own panel to the ChatGPT page and files chats there. It doesn't give ChatGPT any context. Using ConvoShelf as the example:

  • Folders are labels. Filing a chat in a folder doesn't change its instructions, files or memory.
  • Works with Projects. ConvoShelf works on chats inside ChatGPT Projects, so a project chat can also sit in a folder.
  • Several AIs, one list. The same folders appear on chatgpt.com, claude.ai, gemini.google.com and grok.com.
  • Tags, pins and search. Free: unlimited top-level folders, tags and pinned chats, and search over the words inside chats you've opened or indexed (no chat-count cap). You can also import ChatGPT's or Claude's data export to search older chats.
  • Subfolders are Pro. Pro is $4.99 once and adds subfolders up to three levels deep, search filters and bulk move, tag and pin.
  • Local only. Folders and saved chat text stay in your browser on that computer, with no account. That also means no phone app and no sync between computers, apart from a backup file you can restore.

When to use which

  • Use a project for ongoing work where ChatGPT should keep reading the same files or follow the same instructions: a course, a client brief, a long writing project.
  • Use folders for the hundreds of one-off chats that only need a home, for chats made with a GPT, and for topics that span ChatGPT and Claude or Gemini.
  • Use both when you have a few real workspaces. Keep them as projects, and file their chats in folders next to related chats from other AIs.

One caution before you clean up: OpenAI says deleting a project permanently removes its chats. If you only wanted to tidy your sidebar, moving chats out (Remove from project) or filing them in folders is safer. For keeping your own copy, see how to export a ChatGPT conversation. FAQ

Are ChatGPT Projects the same as folders?

Not quite. OpenAI describes projects as keeping related chats, files and instructions together so ChatGPT can use that context. A folder only files a chat and doesn't change how ChatGPT answers.

How many ChatGPT projects can I create?

OpenAI's help page says users can create an unlimited number of projects. File uploads per project depend on the plan: 5 on Free, 25 on Go and Plus, 40 on Pro, Business, Enterprise and Edu.

Why can't I move a chat into a ChatGPT project?

OpenAI says chats created with a GPT can't be moved into a project, and that if Move to project doesn't appear, the chat may not be eligible. A folders extension can still file those chats.

Does deleting a ChatGPT project delete its chats?

Yes. OpenAI says deleting a project permanently removes its chats and instructions, along with files stored only in the project. Files saved separately in Library are not deleted.

Can I use ConvoShelf folders with ChatGPT Projects?

Yes. ConvoShelf works on chats inside ChatGPT Projects, so a chat can stay in its project and also sit in a ConvoShelf folder.
