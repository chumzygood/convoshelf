Privacy policy

Last updated __CS140_LIVE_DATE__, for ConvoShelf 1.4.0.

What ConvoShelf reads and stores

ConvoShelf reads sidebar titles and open-chat messages on the five supported AI hosts. When you start indexing or export, it also reads the signed-in site’s chat lists and conversation messages. Gemini history indexing is limited to sidebar entries and loaded messages. ChatGPT and Claude exports selected in Options are read locally. Live and imported transcripts are stored in extension-origin IndexedDB; structure, settings and an expendable recent-chat cache are also kept in local extension storage. No chat library or transcript is uploaded to ConvoShelf. There is no ConvoShelf account or library-hosting server.

Network requests

Polar license verification sends the license key and ConvoShelf organization ID when you confirm a key and on later rechecks (normally every three days, with 12-hour retries after a negative validation; the alarm checks every 12 hours). Optional site fixes request https://convoshelf.com/fixes/v1.json without cookies, identifiers, query parameters or chat data; the default-on switch can be turned off. No site-fix request is made at first start or install. The first fetch happens only after you have seen the notice containing the “Get site fixes from convoshelf.com” off switch (we record when it was shown); then at most every 12 hours. If you turn it off before then, ConvoShelf never fetches while it is off. The server can see your IP address. User-started indexing, full export and confirmed archive/delete make requests only to the AI site you are signed into, using that site’s session, never to ConvoShelf. Pro browser sync, if turned on, goes through the browser vendor’s own sync service. ConvoShelf never presses Send.

Optional browser sync

Browser sync is Pro and off by default. It uses your browser vendor’s sync account for folders, filing, tags, pins, saved prompts and chains (including saved text), and clip references. Chat titles, transcripts, message text, snippets, clip bodies, labels and anchors, bookmarks (including highlights and notes), settings and licenses do not sync. Text you save in a prompt does sync. New devices show untitled chat and generic clip references until read locally. The library must fit within 100 KB. Turning sync off stops updates on this device and keeps local and existing vendor sync data. Chrome, Edge and Firefox use separate services.

Actions on your AI site

Archive or delete on the AI site only when you confirm the exact count and titles. Archive is available on ChatGPT. Delete is available on ChatGPT, Claude accounts with one organization, and Grok; Gemini site actions are unavailable. Delete requires typing DELETE <count>. Archive is free; delete is free for up to 10 eligible chats per run, Pro above 10. Runs are paced and cancellable, skip other-site chats, and show per-chat results. Options has a global Dry-run mode that makes no site-action requests. Pro offers Export these first before deletion. Deleting on the site cannot be undone; an export restores a local copy only.

Site-change fixes

A site-changed banner pauses affected features. Get site fixes from convoshelf.com is on by default and can be turned off in Options. It checks a settings-only JSON file with no cookies, identifiers or chat data. No site-fix request is made at first start or install. The first fetch happens only after you have seen the notice containing the “Get site fixes from convoshelf.com” off switch (we record when it was shown); then at most every 12 hours. If you turn it off before then, ConvoShelf never fetches while it is off. Fixes contain no code. A fix depends on compatible data being available; no repair time is promised.

Extension and website privacy

The extension has no analytics, ads or trackers. No sale of data or remote code. This website uses GoatCounter, a privacy-friendly, cookie-free counter, to count page views and button clicks. If you answer the optional one-question survey on the Pro page, your choice and any words you type in its optional box are sent to GoatCounter the same way, with no name or email attached. It sets no cookies, stores no personal data, and does not track you across sites.

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Deleting your data

Options → Delete all ConvoShelf data removes local library data and imported chats while keeping your Pro license. Uninstalling removes local extension data. Turn browser sync off on every device first if you want to keep other devices from restoring shared structure; disabling sync or erasing local data does not remove existing vendor sync data. Use the browser vendor’s extension-data controls for a complete sync reset. Erasing ConvoShelf data does not delete chats from an AI site. Site deletion is a separate confirmed action and cannot be undone on that site.

X Bookmarks Shelf, Saved Shelf for Reddit and Watch Later Shelf

The same rules apply to each Shelf extension. They read only the list page you open (your X bookmarks, your Reddit saved page, a YouTube playlist) and store what they read in your browser's local storage. They have no account, no server and no analytics. Saved Shelf's import asks reddit.com for your own saved list while you are signed in; that request goes to Reddit, never to us. The only other requests any of them make go to Polar (api.polar.sh), and only if you use Pro: one when you confirm a Pro license key, then one every 3 days to re-check that key. If Polar reports the key as not found, the extension asks once more 12 hours later before it turns Pro off. Each request carries only the license key and our Polar organization ID. Chrome asks your permission before the first one.
