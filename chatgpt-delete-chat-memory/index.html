Does deleting a ChatGPT chat delete its memories?

Updated October 27, 2026 · 4-minute read

No: deleting a ChatGPT chat doesn't necessarily delete a saved memory that was made from it, because OpenAI stores saved memories separately from your chat history. To make ChatGPT forget something, you delete the memory itself and the chat, and then check the other places the information might sit.

Disclosure: ConvoShelf is our product. Everything about ChatGPT's memory on this page comes from OpenAI's Memory help article, which we read on October 27, 2026.

Where ChatGPT keeps what it remembers

OpenAI says Memory can draw on several sources, depending on your plan and region:

  • past chats
  • saved memories
  • custom instructions
  • files in Library
  • content from connected apps, such as Gmail

Saved memories are the details you ask ChatGPT to remember, or that it saves as useful context. They live apart from your chats. Reference chat history is a separate setting that lets ChatGPT draw on past conversations directly. That's why deleting one thing often leaves another behind.

OpenAI also notes that deletion takes time to propagate, and that it may keep logs of deleted saved memories for up to 30 days for safety and debugging.

How to clean up properly

OpenAI's own advice is to delete the saved memory and the chat where you first shared the information, then remove it from every other place it appears. In practice:

  1. Open the Memory settings. Go to Settings, then Personalization, then Memory. The controls you see vary by account, but this is where you manage saved memories and the memory summary.
  2. Delete the memory. Remove the item from saved memories or the memory summary. You can also ask ChatGPT what it remembers about you to find it.
  3. Delete the chat, including any archived copy. OpenAI lists regular and archived chats as places the information can stay.
  4. Check files and apps. Delete related files from Library, and disconnect a connected app if you don't want ChatGPT reading it anymore.
  5. Use a temporary chat next time. OpenAI says temporary chats don't create or update memories, even with personalization on, unless you save them.

Locked chats follow their own rules: they can use your regular memory, but new messages sent while a chat is locked don't personalize regular chats. Our page on ChatGPT locked chats covers how they work.

FAQ

Does deleting a ChatGPT chat delete what ChatGPT remembers?

Not necessarily. OpenAI says saved memories are stored separately from chat history, and deleting the original chat doesn't necessarily delete a saved memory made from it. Delete the memory in Settings, Personalization, Memory too.

Does turning off Memory delete my chats?

No. OpenAI says turning off Memory does not delete your past chats. If you turn Memory back on later, ChatGPT may create new memories from chats still in your history.

How long does it take for ChatGPT to forget?

If you turn off Reference chat history, information remembered from past chats is scheduled for deletion within 30 days. OpenAI may keep logs of deleted saved memories for up to 30 days for safety and debugging.

What does Don't mention this again do?

It reduces future references to that information, but OpenAI says it does not delete the original chat, file or other source. Use Delete if you want the information gone.
