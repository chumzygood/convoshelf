ChatGPT data export ZIP incomplete or won't extract: what to try

Published November 24, 2026 · 5-minute read

If your ChatGPT export ZIP won't open, or 7-Zip says "Unexpected end of archive", the download most likely stopped before the end. A ZIP keeps its file index in its last bytes, so a cut-off file can't be extracted. Download it again inside the 24-hour link window, try a different browser (Firefox's pause and resume worked for one user), and if it keeps failing, contact OpenAI Support with the error, your browser and device, and the ZIP size.

Disclosure: ConvoShelf is our product. The ChatGPT facts below come from OpenAI's Help Center article Exporting your ChatGPT history and data (it showed "Updated: 17 hours ago" when we read it on November 24, 2026) and from user reports on the OpenAI community forum. The ConvoShelf facts come from the code of version 1.2.0, the version live on the Chrome Web Store, Firefox Add-ons and Edge Add-ons.

Why a big export ZIP won't open

A ZIP file starts with the files themselves and ends with a central directory, the index that says where each file sits. If the download stops early, the start of the file looks like a normal ZIP but the index is missing, so Windows, macOS Archive Utility and 7-Zip all refuse to extract it.

Large ChatGPT exports seem to hit this most. On the OpenAI community forum:

  • On November 18, 2026 a user wrote that an export that should have been about 4.25 GB stopped well short several times, and 7-Zip reported "Unexpected end of archive". A second user replied that their export was cut off the week before.
  • On October 23, 2026 a user downloaded the same export several times in Chrome and Firefox on Windows 11 and got files from about 663 MB to 3 GB. All of them were missing the end-of-central-directory signature.
  • An earlier wave of corrupted Privacy Portal exports got a reply from OpenAI Support on September 16, 2026 saying a fix had been deployed. The November reports came after that, and the cause of the newer cut-offs hasn't been explained.

How to tell your ZIP is cut off

  • The file size changes from one download to the next. A complete export is the same file every time.
  • On Windows, 7-Zip's Test archive shows "Unexpected end of archive".
  • On a Mac or Linux, run unzip -t on the file. A cut-off ZIP fails with "End-of-central-directory signature not found". macOS Archive Utility only shows a generic error.

What to try, in order

  1. Wait for the download to finish. OpenAI's help page says to check the ZIP has finished downloading before you extract it. Look at the browser's download list, not only the file on disk.
  2. Download it again from the same email. The link from a ChatGPT settings export expires 24 hours after you receive it, and OpenAI says to download while signed in to the same account that requested the export. If a link won't open on your phone, try it on a computer.
  3. Try another browser. The November 18 poster says that in an earlier incident, Firefox's own pause, resume and retry controls on the same download recovered the full file. They suggest trying that before anything technical.
  4. Request a fresh export if the link has expired. In ChatGPT, open Settings, then Data controls, and under Export data select Export. Wait for any earlier request to finish first, and allow up to 7 days. If you can't sign in, OpenAI's Privacy Portal takes the request instead.
  5. Contact OpenAI Support. If the download stops or the completed ZIP still won't extract, OpenAI asks you to include any error message, your browser and device, and the ZIP size if available.

Don't paste your export link, cookies or login details into a forum post or a stranger's script. The export holds your chat history and account data, and the link can give access to it. The November 18 poster makes the same request.

Check the export once it opens

A ZIP that extracts can still be missing chats you expected. OpenAI's page says to open index.html from the extracted folder, select Choose folder, pick the export folder, and search for the conversations you need. The viewer runs in your browser and doesn't upload anything. If chats are missing, confirm you exported the right account or workspace, then tell OpenAI Support what is missing, with rough dates. An export can't bring back chats that were already deleted, so check it before you delete anything or move to a managed workspace.

What we saw when we cut a test ZIP

We built an export-shaped test ZIP (a conversations.json with 3,000 short chats plus a chat.html), then kept only the first 60% of the bytes, the way an interrupted download leaves it. unzip -t stopped with "End-of-central-directory signature not found", the same line users quote from real ChatGPT exports. ConvoShelf 1.2.0's ZIP reader, run on the same file, failed at the same point because it found no end-of-directory record, while the uncut original opened with both files listed. In the extension, that failure is shown as: "This ZIP is damaged or incomplete, so it could not be read. Download it again from the ChatGPT email and retry. Nothing was changed."

Importing a complete export into ConvoShelf

ConvoShelf can't repair a ZIP or download one for you. Once you have a complete export, this is what it does with it, checked in the 1.2.0 code:

  • Takes the ZIP as ChatGPT sends it. The Import box on ConvoShelf's options page accepts the ZIP, or the conversations.json inside it. Exports split into numbered conversations files are read too. Everything is read on your computer, and nothing is uploaded.
  • Checks before it changes anything. If the ZIP has no index, a checksum doesn't match, or the conversations file ends mid-way, the import stops with a plain message and leaves your existing data as it was.

  • Limits. Up to 20,000 imported chats. A very long chat keeps its most recent 400,000 characters. Import and search are on the free plan; search filters by AI, folder, tag and date are Pro ($4.99 once).

FAQ

Why won't my ChatGPT export ZIP open?

Usually because the download stopped before the end. A ZIP keeps its file index in its last bytes, so a file that was cut off can't be extracted even if the browser said the download finished. 7-Zip reports this as "Unexpected end of archive" and unzip as "End-of-central-directory signature not found".

How long is the ChatGPT export download link valid?

OpenAI says the link from a ChatGPT settings export expires 24 hours after you receive it, and you should download it while signed in to the same account that requested it. If it has expired, request a new export.

What should I send OpenAI Support if the ZIP keeps failing?

OpenAI's help page asks for any error message, your browser and device, and the ZIP file size if available. Don't post your export link or cookies anywhere, because the link can give access to your data.

Can a ZIP repair tool fix a cut-off ChatGPT export?

Not reliably. The missing part is the end of the file, which never reached your computer. A repair tool may salvage some files from the part you have, but the dependable fix is a complete download.

Can ConvoShelf open a damaged ChatGPT export?

No. ConvoShelf 1.2.0 reads the export ZIP on your computer, and if the ZIP or the conversations file is cut off it stops with a message saying so and changes nothing. Once you have a complete ZIP, it imports up to 20,000 chats and makes them searchable.
