How to organize Claude chats into folders

Published November 25, 2026 · 5-minute read

Claude has no plain folders for chats, so you either group chats into Claude Projects (free accounts can create up to five) or add a browser extension such as ConvoShelf, which puts a folder panel on claude.ai. Projects are free and built in, so try them first.

Disclosure: ConvoShelf is our product. The Claude details below come from Anthropic's Claude Help Center articles What are projects? and How can I create and manage projects?, read on November 25, 2026. The ConvoShelf details come from its Chrome Web Store listing and the 1.2.0 extension code.

Option 1: Claude Projects

A project is Claude's way of grouping chats. Each project has its own chat history, a knowledge base of files you upload, and project instructions that apply to every chat in it. Anthropic says projects are available to all users, and that free users can create a maximum of five.

  1. Open Projects from the left side of claude.ai, or go to claude.ai/projects.
  2. Click + New Project and give it a name, such as a client, a course or a trip.
  3. To move an existing chat in, click the dropdown arrow next to the chat's name and choose Add to project, then pick the project.
  4. Use the same dropdown to remove a chat from a project or move it to another one.
  5. Star the projects you use most so they show up in the left side panel, and archive finished ones. Anthropic says archived projects move to the bottom of the list and their conversations stay accessible.

Where Projects stop working as folders

  • Five on a free account. If you want a group for every client or topic, you run out quickly.
  • A project changes the answers. Claude uses the project's files and instructions in every chat inside it. That's the point of a project, but it means a project is a workspace, not a neutral label.
  • Each project has its own memory. Anthropic says Claude uses the project's memory, plus your memory from chats outside projects, but not memory from other projects.
  • One place per chat. The help center describes moving a chat into a project or between projects, so a chat lives in one project at a time. There are no tags and no subfolders inside a project.
  • Claude only. A project can't hold your ChatGPT or Gemini chats on the same topic.
  • Projects are changing. Anthropic is rolling out a new version of projects in beta, starting with Claude Code, where a project becomes one conversation that splits work into threads. It says existing projects move over with their chat history intact.

Option 2: plain folders with an extension

If you just want to file chats, a folders extension is the closer fit. ConvoShelf is a browser extension that adds a panel to claude.ai (and to chatgpt.com, gemini.google.com and grok.com). A folder there is only a label: it doesn't change what Claude knows or how it answers.

  1. Add ConvoShelf to Chrome, Firefox or Microsoft Edge on your computer, then open claude.ai.
  2. Press Alt+Shift+S, or click the ConvoShelf icon, to open the panel.
  3. Click New folder and name it.
  4. Drag a chat from Claude's sidebar onto the folder, or open the chat and press + on the folder to file it.
  5. Press Alt+Shift+F to search. Search covers the words inside chats you have opened since installing, and titles from Claude's sidebar as soon as ConvoShelf sees them.

Your Claude projects stay as they are, and a chat that lives in a project can also go in a ConvoShelf folder. The free plan has unlimited top-level folders, tags and pinned chats, search, and export of the open chat to Markdown or PDF. Pro is $4.99 once and adds subfolders up to three levels deep, search filters by AI, folder, tag and date, and bulk move, tag and pin.

What it can't do: it doesn't sync to your phone, it only knows the text of Claude chats you have opened while it was installed, and it can't import Claude's official data export (it imports ChatGPT's). Folders, tags and saved chat text stay in your browser; there is no ConvoShelf account or server. To keep a copy of your Claude chats, see how to back up Claude chats.

Which one to use

  • Use Projects when a group of chats should share the same files or instructions, or when you want the grouping on your phone too.
  • Use folders when you have more groups than five, want a chat to sit beside related ChatGPT or Gemini chats, or just want to find a chat later without changing how Claude answers.
  • Use both if you like: keep a few real workspaces as projects, and file everything else in folders.

If you also use Gemini, Claude and Gemini chat folders compares Projects with Gemini notebooks. For ChatGPT, see how to organize ChatGPT, Claude, Gemini and Grok chats into folders.

FAQ

Does Claude have folders?

Not plain folders. Claude has Projects, which group chats with their own files, instructions and memory. There are no tags and no subfolders for chats.

How many projects can I make on a free Claude account?

Anthropic's help center says free users can create a maximum of five projects. The article gives that limit for free users only.

How do I move a Claude chat into a project?

Click the dropdown arrow next to the chat's name, choose Add to project, then pick the project. The same menu moves a chat between projects or removes it.

Can a Claude chat be in two projects?

Anthropic's help center describes moving a chat into a project or between projects, so a chat sits in one project at a time. A folders extension lets you file it in a folder as well, without changing the project.

Will a folders extension change how Claude answers?

No. A ConvoShelf folder is only a label in a panel on claude.ai. Only Claude Projects give Claude shared files and instructions.
