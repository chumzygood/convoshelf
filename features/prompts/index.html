Why it helps

Stop retyping the same instructions in every chat.

How to use it

  1. Open the Prompts tab and click + New prompt.
  2. Give it a title and the prompt text, then save.
  3. On any supported AI, click the prompt. ConvoShelf fills the chat box.
  4. Read it and press Send yourself. ConvoShelf never sends for you.
