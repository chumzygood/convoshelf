Browser sync

ProIn 1.3.0 · in Chrome review

Sync folders, filing, tags, pins and saved prompts across your computers through your browser's own sync account.

11 second silent video with captions, recorded on a demo page with sample chats.

Version 1.3.0 was sent to the Chrome Web Store on Nov 26, 2026. It reaches you when the store approves it.

Why it helps

Set up once, see the same folders at work and at home.

How to use it

  1. Open ConvoShelf Options on each computer.
  2. Turn on Browser sync (Pro). It is off by default.
  3. Chat titles and text never sync; each computer reads them from the site.

Free or Pro

Part of ConvoShelf Pro, a one-time purchase. See Pro.
