ChatGPT nested folders: why there are none, and how to get subfolders

Published November 22, 2026 · 4-minute read

ChatGPT has no nested folders: its Projects are a single level, and OpenAI's help page describes no way to put a project or folder inside another one, so the only way to get subfolders for your chats today is a browser extension such as ConvoShelf.

Disclosure: ConvoShelf is our product. The ChatGPT facts below come from OpenAI's Help Center article Projects in ChatGPT, which showed "Updated: 2 days ago" when we read it on November 22, 2026. The ConvoShelf facts come from the code of version 1.2.0, the version live on the Chrome Web Store, Firefox Add-ons and Edge Add-ons, and from our Pro page.

What ChatGPT gives you instead of folders

ChatGPT's way to group chats is Projects. OpenAI says a project keeps related chats, files and instructions together, so ChatGPT can use the same context across those chats. What its help page describes:

  • Create a project: select New project in the sidebar (the plus icon on mobile), then give it a name, an icon and a color.
  • Move chats in: drag a chat onto the project, or open the chat's menu and select Move to project. Pinned chats can be moved when Move to project is available.
  • Move chats out: Remove from project, in the chat's ••• menu, sends it back to your chat history.
  • Some chats can't move: chats created with a GPT can't be moved into a project.

That's the whole structure. The article doesn't describe a project inside a project, a folder inside a project, or any other level below a project. A project with 40 chats is one flat list.

People are asking for it

When a post on X on November 12, 2026 asked "How can codex be improved?", it drew more than 13,000 replies. One reply listed seven requests, including "Allow pinned chats in projects" and "Support nested folders for projects & chats". OpenAI hasn't announced nested folders, and the Projects help page still doesn't mention them.

How to get nested folders for ChatGPT chats

ConvoShelf adds a folder panel next to ChatGPT, Claude, Gemini and Grok. Its folders live in your browser, on top of the chat list, so they don't depend on Projects. Here is how nesting works, checked in the 1.2.0 code:

  1. Make a top-level folder. Press + New folder in the ConvoShelf panel. Top-level folders are unlimited on the free plan.
  2. Add a subfolder. Open the folder's ••• menu and choose New subfolder. This is a Pro feature; on the free plan the menu shows "New subfolder (Pro)".
  3. Go up to three levels. A folder, a subfolder and a subfolder inside that. ConvoShelf stops at three levels deep.
  4. File chats. Drag a chat from the ChatGPT sidebar onto any folder, or open the chat and press + on a folder. Filing adds the chat to that folder without taking it out of others, so one chat can sit in several folders.

A few details from the code that matter once you have a tree:

  • Deleting a folder deletes its subfolders too. The chats aren't deleted.
  • Export folder (Pro) writes one Markdown file with the chats in that folder and every subfolder under it.
  • If you restore a backup with folders nested deeper than three levels, the deeper ones are placed at level three. Nothing is removed.
  • Subfolders you already have, including ones from an imported backup, stay usable on the free plan. Only creating new ones is Pro.

ConvoShelf works on chats inside ChatGPT Projects too. A chat can stay in its project, where ChatGPT uses the project's files and instructions, and also sit in a ConvoShelf subfolder like Clients / Acme / Invoices. The project is still there on your phone; the ConvoShelf folders are only in the browser where you made them.

FAQ

Does ChatGPT have nested folders?

No. ChatGPT has Projects, which group chats, files and instructions. OpenAI's Projects help page, read on November 22, 2026, describes creating projects and moving chats into them, and has no option for putting a project or folder inside another one.

Can I put a ChatGPT project inside another project?

Not according to OpenAI's Help Center. Its Projects page covers creating a project, moving chats in with drag and drop or Move to project, and Remove from project, with no step for nesting projects.

How do I get subfolders for my ChatGPT chats?

Use a browser extension that adds its own folders. In ConvoShelf, open a folder's menu and choose New subfolder. Creating subfolders is part of ConvoShelf Pro, $4.99 once, and folders go three levels deep.

Are ConvoShelf subfolders free?

Top-level folders are unlimited on the free plan. Creating new subfolders is Pro. Subfolders you already have, including any that came from an imported backup, stay usable on the free plan.

Do ConvoShelf folders change my ChatGPT Projects?

No. ConvoShelf keeps its folders in your browser's local storage and doesn't move chats on ChatGPT. A chat can stay in its project and also sit in one or more ConvoShelf folders.
