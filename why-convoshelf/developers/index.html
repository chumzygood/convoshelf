What you can check for yourself

  • The Chrome Web Store listing shows the current version (1.0.1, updated October 19, 2026).
  • The extension only asks to run on chatgpt.com, chat.openai.com, claude.ai, gemini.google.com and grok.com. The Polar license check is an optional permission you approve only if you buy Pro, and it sends the key, never your chats.
  • There is no ConvoShelf account and no ConvoShelf server. Delete everything from the options page with Delete all ConvoShelf data.

Questions

Which AI sites does ConvoShelf work with?

ChatGPT (including Projects), Claude, Gemini and Grok.

Is ConvoShelf free?

Yes. The free plan has unlimited folders and subfolders, full-text search, export of the open chat to Markdown or PDF, and 10 saved prompts, with no time limit.

Is Pro a subscription?

No. Pro is a single $4.99 payment through Polar, with no renewal.

Where are my chats stored?

In your browser's local storage. ConvoShelf has no account and no server.
