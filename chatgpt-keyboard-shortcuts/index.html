ChatGPT keyboard shortcuts: the desktop app list and the web keys

Published November 19, 2026 · 4-minute read

The ChatGPT keyboard shortcuts most people need are Ctrl+K (Cmd+K on a Mac) to search your chats on chatgpt.com and, in the ChatGPT desktop app, Ctrl+Shift+O for a new chat and Ctrl+/ to show the full list.

Disclosure: ConvoShelf is our product. The ChatGPT shortcuts below come from OpenAI's Commands reference for the desktop app and its Help Center article on finding your chats, projects and files, both read on November 19, 2026. The ConvoShelf keys come from the code of version 1.2.0, the version live on the Chrome Web Store, Firefox Add-ons and Edge Add-ons, checked the same day.

Shortcuts on chatgpt.com

OpenAI's Help Center documents one shortcut for the website: press Ctrl+K on Windows or Cmd+K on macOS to open Search. Search looks through your chat titles and messages, archived chats, projects, images and files. It doesn't find deleted chats, and locked chats stay out of regular search until you open them from Projects > Locked chats.

OpenAI doesn't publish a full list of the website's keys in its Help Center, and the keys below are documented for the desktop app. Some may also work on the website, but we haven't listed any we couldn't source.

Two things trip people up. First, Ctrl+K does different things in the two places: it opens Search on the website but the command menu in the app. Second, the app has no default key for Search chats; you can assign one under Settings > Keyboard Shortcuts, where you can also change or reset any shortcut.

A keyboard palette for your saved chats

ChatGPT's shortcuts move you around ChatGPT. If you also use Claude, Gemini or Grok, or you keep chats in folders and reuse prompts, ConvoShelf adds three keys of its own in the browser:

  • Alt+Shift+K opens the ConvoShelf command palette.
  • Alt+Shift+S opens or closes the ConvoShelf panel.
  • Alt+Shift+F searches all your saved chats.

On a Mac, Alt is the Option key. The palette is one text box and one list. Type to find a saved chat and jump to it, run a saved prompt or prompt chain, move the open chat to a folder, export it as Markdown or PDF, make a new folder, or search every saved message for what you typed. Start with > for actions only, / for prompts, # for folders or @ for chats. Arrow keys move, Enter runs and Esc closes.

We built it to stay out of ChatGPT's way. In the 1.2.0 code, the palette never listens for Ctrl+K or Cmd+K, so ChatGPT's own Search key still works. Running a prompt puts the text in the message box, and if the box already has your draft, ConvoShelf asks before replacing it. ConvoShelf never presses Send.

The palette is on the free plan, and it works on chatgpt.com, claude.ai, gemini.google.com and grok.com. If a key clashes with something else, change it on your browser's extension shortcuts page (chrome://extensions/shortcuts in Chrome, edge://extensions/shortcuts in Edge, or Manage Extension Shortcuts on Firefox's add-ons page).

FAQ

What is the keyboard shortcut to search chats in ChatGPT?

On chatgpt.com, press Ctrl+K on Windows or Cmd+K on a Mac to open Search, per OpenAI's Help Center. In the desktop app, Ctrl+K opens the command menu instead, and Search chats has no default key until you assign one in Settings > Keyboard Shortcuts.

How do I start a new chat in ChatGPT with the keyboard?

In the ChatGPT desktop app, press Ctrl+N or Ctrl+Shift+O on Windows, or Cmd+N or Cmd+Shift+O on a Mac. Ctrl+Shift+N (Cmd+Shift+N) starts a temporary chat instead.

How do I see all ChatGPT keyboard shortcuts?

In the desktop app, press Ctrl+/ on Windows or Cmd+/ on a Mac, or open Settings > Keyboard Shortcuts, where you can also change or reset them. OpenAI's Commands page lists the defaults for Windows, macOS and Linux.

Can I change ChatGPT keyboard shortcuts?

In the desktop app, yes: Settings > Keyboard Shortcuts lets you find, customize or reset them. ConvoShelf's own keys are set in your browser's extension shortcuts page instead.

Does ConvoShelf's palette conflict with Ctrl+K?

No. ConvoShelf opens its palette with Alt+Shift+K and never listens for Ctrl+K or Cmd+K, so ChatGPT's own Search key keeps working. The palette never sends a message for you.
