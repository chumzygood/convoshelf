FAQ

How do I install it?

Get it from the Chrome Web Store: Add to Chrome, free. The free plan has no time limit. Pro is $4.99, paid once.

Do I need an account?

No. There is no ConvoShelf account and no ConvoShelf server.

Where are my folders stored?

In your browser's local extension storage. Use Backup in settings to save a JSON file; Restore merges it back.

Does it work with ChatGPT Projects?

Yes. Chats inside a Project can be filed, searched and exported like any other chat.

Why doesn't search find an old chat?

ConvoShelf indexes a chat's text when you open it. Open older chats once and they become searchable. Titles from the sidebar are picked up as you browse.

How do I export a long chat?

Scroll to the top of the chat so every message is loaded, then use Export. PDF opens the print dialog; pick "Save as PDF".

Which sites?

chatgpt.com, claude.ai, gemini.google.com and grok.com.

What does Pro cost?

$4.99, paid once. It adds bulk export, JSON export, search filters, bulk actions, folder colors and unlimited prompts.

A site changed and something stopped working.

Open the ConvoShelf popup: the Self-check list shows which site needs an update. Email toolshed+convoshelf@mail.grokbot.com and we will ship a fix.
