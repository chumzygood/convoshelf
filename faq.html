FAQ

How do I install it?

Get it from the Chrome Web Store: Add to Chrome, free. Version 1.4.1 reached the Chrome Web Store on November 28, 2026. Firefox Add-ons also offers 1.4.1. Edge is still on 1.2.0 until that store finishes its review. Also on Firefox and Edge. The free plan has no time limit. Pro is $4.99, paid once.

Do I need an account?

No ConvoShelf account is needed. Optional Pro browser sync uses your browser vendor’s account; there is no ConvoShelf library-hosting server.

Where are my folders stored?

Folders and settings are in local extension storage; live and imported chat text is in extension-origin IndexedDB. Use Backup in Options to save a local JSON file; Restore merges it back. Optional Pro browser sync shares structure and saved prompts/chains, subject to a 100 KB limit.

Does it work with ChatGPT Projects?

Yes. Chats inside a Project can be filed, searched and exported like any other chat.

Why doesn't search find an old chat?

Search chats you have opened or indexed, plus imported ChatGPT and Claude exports. Index my history runs only when you start it in a signed-in site tab, with progress, Cancel and resume. ChatGPT includes Projects; Claude and Grok use their signed-in APIs. Gemini indexing is partial: scroll its sidebar and open chats to add loaded messages. Private site APIs can change. The live index has no chat-count cap; device storage limits apply. Imports keep up to 20,000 chats, 400,000 characters per chat and 400 million characters total. Both plans offer Show more in pages of 50; search can report incomplete results when its time budget is reached. Gemini and Grok export import are unsupported.

How do I import my ChatGPT export?

Choose your official ChatGPT or Claude export in Options → Import. ChatGPT ZIP/JSON and Claude conversations JSON, numbered shards and split ZIP parts with their manifest are supported. Select all declared parts together. Cancel or a damaged file rolls the import back. Re-importing updates newer text without duplicates and keeps filing, tags and pins. Unknown formats fail safely.

What is the command palette?

Press Alt+Shift+K (if your browser set that key; you can change it on your browser's shortcuts page) or the ⌨ button in the panel to jump to a chat, run a prompt or chain, file the open chat, export it, or start a search. ConvoShelf never presses Send for you.

How do I export a long chat?

Export tries to read the whole active conversation branch, then load earlier turns. If that cannot be confirmed, the file says incomplete; Gemini and stored or other-site copies are always marked incomplete. Single-chat Markdown and PDF are free. Markdown includes YAML metadata, code fences and image links; unknown metadata is blank and asset links may expire. JSON and bulk export are Pro, including a ZIP of selected chats or a folder and its subfolders, with safe filenames and index.md. Copy as Markdown is available on loaded messages. PDF opens a local print view; choose Save as PDF.

A site changed and something stopped working.

A site-changed banner pauses affected features. Get site fixes from convoshelf.com is on by default and can be turned off in Options. It checks a settings-only JSON file with no cookies, identifiers or chat data. No site-fix request is made at first start or install. The first fetch happens only after you have seen the notice containing the “Get site fixes from convoshelf.com” off switch (we record when it was shown); then at most every 12 hours. If you turn it off before then, ConvoShelf never fetches while it is off. Fixes contain no code. A fix depends on compatible data being available; no repair time is promised. Check the popup’s self-check and email toolshed+convoshelf@mail.grokbot.com if a feature stays paused.

Which network requests does ConvoShelf make?

Network requests: Polar license verification sends the license key and ConvoShelf organization ID when you confirm a key and on later rechecks (normally every three days, with 12-hour retries after a negative validation; the alarm checks every 12 hours). Optional site fixes request https://convoshelf.com/fixes/v1.json without cookies, identifiers, query parameters or chat data; the default-on switch can be turned off. No site-fix request is made at first start or install. The first fetch happens only after you have seen the notice containing the “Get site fixes from convoshelf.com” off switch (we record when it was shown); then at most every 12 hours. If you turn it off before then, ConvoShelf never fetches while it is off. The server can see your IP address. User-started indexing, full export and confirmed archive/delete make requests only to the AI site you are signed into, using that site’s session, never to ConvoShelf. Pro browser sync, if turned on, goes through the browser vendor’s own sync service. ConvoShelf never presses Send.

What’s new in 1.4.1?

1.4.1 adds Highlights. Highlights, on the Clips tab, collects the passages you highlighted, your bookmark notes and your key takeaways from every chat in one list. Search it, jump back to the message, or export it all as Markdown (free). On the free plan, takeaways and bookmarks share the 15-item limit; Pro is unlimited. From 1.4.0: Star a prompt or answer as a bookmark, highlight a passage and keep a private note, then filter bookmarks by AI, folder or tag. Outline lists prompts and answer headings of the loaded chat in reading order and marks where you are; Pro adds a slim navigation rail. Type two slashes (//) at the start of a line or after a space to insert a saved prompt; you review it and press Send, and Options can turn this off. Auto-file rules in Options file new chats into folders, with a preview and Undo; Free keeps two rules and Pro is unlimited. In Export, Pro can select messages and hide email addresses, phone numbers, API keys and tokens, URLs with secret parameters, and any names or words you list, then preview before saving Markdown, JSON or PDF. Bookmarks travel in local backups and stay out of browser sync. Choose the panel’s left or right side or collapse it to a rail. A skippable four-step tour helps new installs; updates show a one-time What’s new in 1.4.1 note. ConvoShelf 1.4.0 ships complete translations of the panel, popup and Options in English, German, Spanish, French, Japanese and Brazilian Portuguese. The keyboard-shortcut descriptions in the browser’s shortcut settings stay in English.

Can ConvoShelf delete chats?

Archive or delete on the AI site only when you confirm the exact count and titles. Archive is available on ChatGPT. Delete is available on ChatGPT, Claude accounts with one organization, and Grok; Gemini site actions are unavailable. Delete requires typing DELETE <count>. Archive is free; delete is free for up to 10 eligible chats per run, Pro above 10. Runs are paced and cancellable, skip other-site chats, and show per-chat results. Options has a global Dry-run mode that makes no site-action requests. Pro offers Export these first before deletion. Deleting on the site cannot be undone; an export restores a local copy only.

What does browser sync share?

Browser sync is Pro and off by default. It uses your browser vendor’s sync account for folders, filing, tags, pins, saved prompts and chains (including saved text), and clip references. Chat titles, transcripts, message text, snippets, clip bodies, labels and anchors, bookmarks (including highlights and notes), settings and licenses do not sync. Text you save in a prompt does sync. New devices show untitled chat and generic clip references until read locally. The library must fit within 100 KB. Turning sync off stops updates on this device and keeps local and existing vendor sync data. Chrome, Edge and Firefox use separate services.
