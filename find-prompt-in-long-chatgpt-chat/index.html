How to find a prompt you asked in a long ChatGPT chat

Published November 28, 2026 · 4-minute read

To find a prompt in a long ChatGPT chat, scroll up once so the older turns load, then search the page for a word you remember, or open a prompt outline such as ConvoShelf's free Outline tab, which lists every question you asked in the chat and jumps to the one you click.

Disclosure: we make ConvoShelf, a browser extension for ChatGPT, Claude, Gemini and Grok chats. ChatGPT's search behavior below is from OpenAI's help article Finding your chats, projects, and files, read November 28, 2026.

What ChatGPT gives you

  • Sidebar search (Ctrl+K on Windows, Cmd+K on Mac) matches words in chat titles and messages. Pick a result and it opens the chat. It finds the conversation, not the place in it, so in a 40-turn chat you're still scrolling.
  • Your browser's Find (Ctrl+F or Cmd+F) searches the text on the page. In a long chat the early turns may not be on the page until you scroll up, so a prompt from the start can be missed.
  • Edited prompts keep earlier versions. If the question you remember was edited, hover over it on desktop and use See versions or the 2/2 arrows. See ChatGPT chat history disappeared? for that and other missing-reply cases.

Use a prompt outline instead

  1. Install ConvoShelf, open the long chat on chatgpt.com, open the ConvoShelf panel and choose Outline.
  2. You get your prompts in reading order, with the headings from ChatGPT's answers in between, and the one you're reading is marked as you scroll.
  3. Type in Search prompts in this chat to narrow the list.
  4. Click a prompt and the chat scrolls to it. The two small buttons next to each prompt copy your prompt or the AI's reply as Markdown.
  5. If an early prompt is missing, scroll up in the chat so the older turns load. The panel says the same: "Prompts loaded in this chat."

What the filter matched in our test

On November 28, 2026 we ran the Outline's matching code from ConvoShelf 1.4.1 (the Chrome Web Store version that day) on a made-up chat with seven prompts about a lease renewal: drafting an email to a landlord, a "break clause" question, a rent increase from £1,250 to £1,310, café hours and a Spanish translation.

  • With the box empty, all 7 prompts were listed. Answers aren't listed as rows, only your prompts (and headings inside answers).
  • "email" and "EMAIL" both found the same 3 prompts: case doesn't matter.
  • "cafe" found "Café opening hours for the meeting?": accents don't matter.
  • "break clause" found the one prompt with that phrase, quotes and all.
  • "landlord email" found nothing, because the prompt said "email to my landlord". The filter looks for the letters in the order you type them, so search one distinctive word, not a phrase you half remember.

The Outline and its filter are free. Pro ($4.99 once, no subscription) adds a slim navigation rail beside the list and lets ConvoShelf's global search open a result at the exact message. ConvoShelf has no account and keeps its data in your browser.

FAQ

How do I find an old question in a long ChatGPT chat?

Scroll up once so the older turns load, then use your browser's Find (Ctrl+F or Cmd+F) for a word you remember. ConvoShelf's free Outline tab lists every prompt in the chat and jumps to the one you click.

Does ChatGPT's search find a message inside a chat?

ChatGPT's sidebar search (Ctrl+K or Cmd+K) matches words in chat titles and messages and opens the chat. It finds the conversation, not the spot in it.

Why can't I find an early prompt in a long chat?

Long chats load in parts. Prompts near the top may not be on the page until you scroll up, so in-page tools can't see them yet.

Is the ConvoShelf Outline free?

Yes. The Outline tab and its prompt filter are on the free plan. Pro ($4.99 once) adds a slim navigation rail and lets global search results jump straight to the message.

Does the Outline filter match whole phrases?

It matches the letters you type, ignoring case and accents, so "cafe" finds "Café". Two words must appear next to each other in that order: "landlord email" didn't match "email to my landlord" in our test.
