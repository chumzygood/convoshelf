ChatGPT, Claude and Gemini folders in Firefox and Microsoft Edge

You don't need Chrome to get folders for your AI chats. ConvoShelf version 1.2.0 is on Firefox Add-ons and Microsoft Edge Add-ons, with the same folders, tags, pins, search and export as the Chrome Web Store version. It works on chatgpt.com, claude.ai, gemini.google.com and grok.com.

Disclosure: ConvoShelf is our product. Version and browser details below were checked on 24 November 2026 against the public Firefox Add-ons listing and the 1.2.0 packages. The Edge install steps come from Microsoft's support page.

Get it for Firefox   Get it for Edge

Install in Firefox

  1. Open the ConvoShelf page on Firefox Add-ons in Firefox on your computer.
  2. Click Add to Firefox, read the permissions, and confirm.
  3. Open chatgpt.com, claude.ai, gemini.google.com or grok.com. The ConvoShelf panel appears on the page. Press Alt+Shift+S to open or close it, and Alt+Shift+F to search your saved chats.

The listing needs Firefox 142 or newer. It is for Firefox on a computer, not Firefox for Android. To change the keyboard shortcuts, go to about:addons, click the gear icon, and choose Manage Extension Shortcuts.

Install in Microsoft Edge

  1. Open the ConvoShelf page on Microsoft Edge Add-ons in Edge.
  2. Click Get, review the permissions, and click Add extension.
  3. Open one of the four AI sites and the panel appears.

Edge can also install extensions from the Chrome Web Store. Microsoft's help page says that if you haven't allowed it yet, Edge shows a dialog to Allow extensions from other stores (Microsoft Support: add, turn off, or remove extensions in Edge). Either listing gives you the same 1.2.0 features. The Edge Add-ons listing is one less step.

What is the same in every browser

  • Sites: ChatGPT, Claude, Gemini and Grok, in one folder list.
  • Free plan, no time limit: unlimited top-level folders, tags and pins, full-text search of chats you have opened (up to 3,000) plus an imported ChatGPT export (up to 20,000 chats), export of the open chat to Markdown or PDF, 10 saved prompts, 10 clips and 1 handoff a day.
  • Pro, US$4.99 once: subfolders up to 3 levels, bulk and JSON export, search filters, bulk move, folder colors, unlimited prompts and clips, one-click handoff, and jump to the exact message from a search result. See what Pro adds.
  • No account: there is no ConvoShelf account or chat-storage server. The only network request is the Pro license check, which sends the license key to Polar.

Moving your folders from Chrome to Firefox or Edge

Because nothing is stored on a ConvoShelf server, a new browser starts empty. To bring your folders and tags across:

  1. In the browser you use now, open ConvoShelf's options page and click Download backup. This saves a .json file.
  2. Install ConvoShelf in the new browser, open its options page, and use Restore from file with that file.

Backup and restore are in the free plan. Search inside older chats depends on chats you have opened in that browser and any ChatGPT export you import there, so open a few chats or import your ChatGPT export again in the new browser.

Questions

Is there a ChatGPT folders extension for Firefox?

Yes. ConvoShelf 1.2.0 is on Firefox Add-ons for Firefox 142 or newer on a computer. It adds folders, tags, pins and full-text search on chatgpt.com, claude.ai, gemini.google.com and grok.com. The free plan has unlimited top-level folders; Pro is US$4.99 once.

Is ConvoShelf on the Microsoft Edge Add-ons store?

Yes. Version 1.2.0 is listed on Microsoft Edge Add-ons. Edge can also install Chrome Web Store extensions after you allow extensions from other stores, but the Edge Add-ons listing is the direct route.

Do my folders sync between Chrome, Firefox and Edge?

No. There is no ConvoShelf account or server, so folders, tags and saved chat text stay in the browser profile where you made them. To move them, use Download backup on the options page in one browser and Restore from file in the other.

Does the Firefox version have the same features as Chrome?

Yes. The Firefox, Edge and Chrome packages of 1.2.0 run the same feature code and cover the same four sites. The free limits and Pro features are the same. Only browser details differ, such as where you change keyboard shortcuts.

Does ConvoShelf work in Firefox for Android?

No. The Firefox Add-ons listing is for Firefox on a computer, version 142 or newer.
